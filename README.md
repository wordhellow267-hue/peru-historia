# Perú · 5000 años

Experiencia interactiva de 45 segundos sobre la historia del Perú, de Caral a la Guerra del Pacífico. Hecha con React y GSAP, con un estilo de animación inspirado en unitedcarriers.com.

## Ver en local

```bash
python -m http.server 5173
```

Abre http://localhost:5173 y pulsa **Comenzar**.

## Controles

- Rueda del ratón o arrastrar: avanzar o retroceder en el tiempo
- Espacio: pausa
- ← →: capítulos
- M: sonido
- Clic en un retrato: ficha del personaje

## Créditos de imágenes

Todas las imágenes de `assets/` provienen de Wikimedia Commons y son de dominio público o de licencia libre: obras de Juan Lepiani, Martín Tovar y Tovar, Arturo Michelena, Thomas Somerscales; retratos de la escuela cusqueña (Brooklyn Museum) y fotografías de Machu Picchu, Caral y Vinicunca.
